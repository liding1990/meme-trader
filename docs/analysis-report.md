# Solana Memecoin DNA 四维聚类分析报告

## 一、研究概述

### 1.1 研究背景与目标

Memecoin 市场是加密货币领域中波动最剧烈、生命周期最短的细分赛道。大量 Memecoin 在创建后数小时内经历从零到数百万美元市值再急速归零的完整生命周期。在如此高速迭代的市场中，理解 token 的行为模式并对新出现的 token 进行快速分类和预判，具有极高的实用价值。

本研究的核心目标是：通过构建一个四维状态空间（时间 × 市值 × 持币地址数 × Top10 持仓集中度），对 Solana 链上的 Memecoin 进行系统性的轨迹聚类分析，发现不同类型 token 的行为 pattern，并建立一套基于历史轨迹匹配的预判框架。

### 1.2 数据来源与样本

数据来源于 GMGN API，采集了 302 个 Solana 链上 Memecoin 的历史数据，最终 193 个 token 通过了 $50K 市值门槛筛选，进入分析样本集。每个 token 的数据包含从首次达到 $50K 市值起的逐小时快照，涵盖以下维度：

- **Market Cap（市值）**：token 每小时的市值，范围从 $50K 到 $2.18 亿
- **Holder Count（持币地址数）**：唯一持币钱包数量，范围从 1 到 152,223
- **Top 10 Holder Percentage（Top10 持仓占比）**：前 10 大持仓地址合计持有的 token 供应量百分比，范围从 0% 到 100%
- **Time（时间）**：从 $50K 市值起的累计小时数，范围从 0 到 200 小时

全部样本共产生 6,853 个状态点（每个 token 每小时一个点），构成了一个密集的四维状态空间。

### 1.3 技术方法论

#### 特征提取：路径签名（Path Signature）

为了在四维空间中对 token 的完整轨迹进行聚类（而非对单个状态点聚类），我们采用了路径签名（Path Signature）技术。路径签名源自粗糙路径理论（Rough Path Theory），通过计算多维路径的迭代积分，将任意长度的多维时间序列压缩为一个固定长度的特征向量。

具体实现中，我们对每个 token 的四维轨迹（time, log(mcap), log(holders), top10%）计算深度为 3 的截断签名，得到 84 维的特征向量。对 mcap 和 holders 取对数是为了处理这两个维度跨越多个数量级的问题——没有对数变换，$553K 和 $181K 的市值在 0~$2.18 亿的线性尺度上几乎无法区分。

#### 降维与聚类：UMAP + HDBSCAN

84 维的签名向量对于密度聚类算法来说维度仍然偏高（"维度灾难"会导致密度估计失效）。因此我们先用 UMAP 将 84 维降至 10 维，保留核心的拓扑结构，再使用 HDBSCAN 进行密度聚类。

HDBSCAN 的优势在于：不需要预设聚类数量，能自动发现密度不均匀的聚类，并将不属于任何模式的离群 token 标记为噪声。最终参数设置为 `min_cluster_size=5, min_samples=2`。

#### 近邻查询：对数变换 + KD-Tree

对于新 token 的实时预判，我们在四维状态空间中构建了 KD-Tree 索引。关键改进是对 mcap 和 holders 维度进行对数变换后再计算距离，确保同一数量级内的差异能够被有效区分。

## 二、聚类分析结果

### 2.1 聚类总览

193 个 token 被分为 **8 个聚类**，仅 4 个 token 被归为噪声（2.1% 噪声率），说明聚类质量较高，绝大多数 token 都能找到其所属的行为模式类别。

| 聚类 | 数量 | 中位 ATH 市值 | 中位 ATH 时间 | 中位存活时长 | 中位 Holders | 中位 Top10% | MCap 保留率 |
|------|------|-------------|-------------|------------|------------|-----------|-----------|
| C0 | 50 | $843,020 | 6h | **84h** | 2,146 | 15.3% | 2.6% |
| C1 | 42 | $484,432 | 0h | 15h | 1,720 | 16.0% | 1.7% |
| C2 | 5 | $1,569,899 | 1h | 17h | 2,705 | **25.7%** | 27.8% |
| C3 | 16 | $444,025 | 1h | 17h | 3,218 | 18.1% | 20.8% |
| C4 | 16 | $345,204 | 0h | 17h | 2,992 | 19.6% | 43.6% |
| C5 | 20 | $511,783 | 2h | 17h | 1,912 | 21.8% | 43.9% |
| C6 | 20 | $690,872 | 6h | 17h | 3,305 | 17.4% | **72.4%** |
| C7 | 20 | **$1,153,704** | **12h** | 17h | 3,230 | 21.6% | **75.0%** |

> MCap 保留率 = token 最终市值 / ATH 市值，反映 ATH 后的价值留存能力。

### 2.2 各聚类深度解读

---

#### Cluster 0：长寿探索型（50 个 token）

**核心特征**：这是样本中最大的聚类，也是唯一一个中位存活时长远超其他聚类的群体（84 小时 vs 其他聚类的 15-17 小时）。

**代表性 token**：EGG, UGOR, NOTHING, CAPTCHA, DAPANG, GREG, LEGACY, VNUT, PERK

**生命周期画像**：
- **到顶速度**：中位 6 小时到达 ATH，在所有聚类中属于中等偏慢
- **Holder 增长**：到 ATH 时 holder 数中位增长 **+3,533%**，是所有聚类中增长最快的，说明这类 token 在上涨过程中吸引了大量新参与者
- **ATH 后衰退**：尽管存活时间最长，但最终 MCap 保留率仅 2.6%，说明这类 token "活得久但跌得深"
- **Holder 流失**：ATH 后 holder 数中位下降 18%，流失率中等
- **筹码分散**：Top10% 持仓占比中位 15.3%，是所有聚类中最低的，且整体趋势是进一步分散（-1.3pp）

**解读**：C0 代表了一种"社区驱动型"模式。极高的 holder 增速和极低的筹码集中度说明这类 token 在早期成功地建立了广泛的持仓分布，社区参与度高。然而，长存活时间并没有带来价值留存——恰恰相反，漫长的衰退过程意味着大部分参与者都在慢性亏损中逐渐离场。这类 token 的 ATH 范围极广（$199K 到 $2.18 亿），说明"长寿探索型"模式出现在各个市值量级中。

**投资启示**：如果一个 token 在前 6 小时内 holder 增速极快且筹码分散，它很可能属于 C0 类型。虽然它会存活较长时间，但 ATH 后的下跌几乎是不可避免的（97.4% 的价值最终被抹去）。关键时间窗口是前 6 小时——之后大概率进入不可逆的衰退。

---

#### Cluster 1：闪崩型（42 个 token）

**核心特征**：中位 ATH 时间为 0 小时——意味着这类 token 在达到 $50K 市值的那一刻就已经是其历史最高点。

**代表性 token**：DARWIN, TRUMP, EPICFURY, BRAINLET, GOOSE, DELULU

**生命周期画像**：
- **到顶速度**：0 小时（起步即巅峰），ATH 范围从 $112K 到 $1.21 亿
- **Holder 增长**：到 ATH 时 holder 仅增长 +8%，几乎没有新参与者涌入
- **ATH 后衰退**：MCap 保留率仅 1.7%，是所有聚类中最低的
- **Holder 流失**：ATH 后 holder 下降 32%，是所有聚类中流失最严重的
- **筹码集中**：Top10% 从开始到结束反而上升了 +2.5pp，说明大户在逆势吸筹或散户在加速离场

**解读**：C1 是典型的"Pump & Dump"模式。token 在达到 $50K 的那一刻已经完成了价格发现的全部过程，之后就是单边下跌。极低的 holder 增长率说明在突破 $50K 之前就已经没有新的买盘驱动力。Top10% 在衰退过程中反而上升，暗示可能存在庄家在低位回收筹码或大量散户割肉离场导致的被动集中。

**投资启示**：如果一个 token 刚过 $50K 但 holder 增速极低（<10%），极有可能属于 C1 类型。这类 token 几乎没有参与价值——98.3% 的市值将在存活的 15 小时内蒸发。

---

#### Cluster 2：庄控高市值型（5 个 token）

**核心特征**：数量最少的聚类，但中位 ATH 市值高达 $1.57M，同时 Top10% 持仓集中度是所有聚类中最高的（25.7%）。

**代表性 token**：WAR, XMN, PAW, PETAH, Gizmo

**生命周期画像**：
- **到顶速度**：中位 1 小时到达 ATH
- **Holder 增长**：到 ATH 时 holder 仅增长 +2%
- **ATH 后保留**：MCap 保留率 27.8%，高于 C0 和 C1
- **Holder 流失**：ATH 后 holder 仅下降 4%，极低
- **筹码变化**：Top10% 大幅下降 -8.6pp，是所有聚类中下降最多的

**解读**：C2 代表了"庄控盘"模式。高市值 + 高 Top10% 集中度说明市值主要由少数大户支撑。有趣的是，Top10% 在生命周期内大幅下降了 8.6 个百分点，说明大户在持续出货。但 holder 流失率极低（-4%），说明出货是通过大户减仓给散户接盘实现的，而不是大规模抛售导致的恐慌离场。27.8% 的市值保留率也验证了这一点——庄家有序减仓维持了相对稳定的价格。

**投资启示**：Top10% > 25% 的 token 大概率属于此类型。高集中度意味着价格主要由少数地址控制，虽然短期内价值留存较好，但 Top10% 的持续下降暗示大户在出货，散户面临接盘风险。

---

#### Cluster 3：快速冲顶中等型（16 个 token）

**核心特征**：中位 ATH $444K，1 小时到顶，17 小时存活。holder 数量较多（中位 3,218），但 holder 增速为负（-1%）。

**代表性 token**：TOILET, GROKEN, Optimistic, SINGULARITY, CHUD

**生命周期画像**：
- **Holder 增长**：-1%（到 ATH 时 holder 几乎没变化）
- **ATH 后保留**：20.8%
- **Holder 流失**：ATH 后 -10%
- **筹码变化**：几乎不变（-0.0pp）

**解读**：C3 是一种"快速博弈"模式。token 在 1 小时内完成价格发现，holder 基数较大但不再增长，说明参与者主要是在 $50K 之前就已经入场的早期投资者。Top10% 保持不变说明筹码分布在整个生命周期内相对稳定——既没有大户出货，也没有新的集中化趋势。

---

#### Cluster 4：起步即顶但抗跌型（16 个 token）

**核心特征**：和 C1 一样 ATH 时间为 0h（起步即巅峰），但 MCap 保留率高达 43.6%——远高于 C1 的 1.7%。

**代表性 token**：WAR, GROKIUS, WILSON, HENRY, WhiteHouse

**生命周期画像**：
- **到顶速度**：0 小时
- **Holder 增长**：-2%（到 ATH 时 holder 略有减少）
- **ATH 后保留**：43.6%
- **Holder 流失**：ATH 后仅 -11%
- **筹码变化**：Top10% 上升 +4.0pp

**解读**：C4 和 C1 同样是"起步即巅峰"，但 C4 的价值留存能力远超 C1。关键区别在于 holder 流失率——C4 只流失了 11%（vs C1 的 32%），说明持仓者有更强的持有意愿。Top10% 上升 4pp 说明在缓慢下跌过程中散户离场、大户份额被动增加。43.6% 的市值保留率说明这类 token 虽然过了最高点，但仍维持着相当的市场共识。

---

#### Cluster 5：中等集中稳定型（20 个 token）

**核心特征**：中位 ATH $512K，2 小时到顶，Top10% 较高（21.8%）。

**代表性 token**：VDR, TRENCH, NoLimit, BIGTROUT, JELLYBEAN

**生命周期画像**：
- **Holder 增长**：0%（到 ATH 时 holder 无变化）
- **ATH 后保留**：43.9%
- **Holder 流失**：仅 -5%
- **筹码变化**：-0.2pp（几乎不变）

**解读**：C5 是最"稳定"的类型之一。所有指标变动都很小——holder 不增不减、Top10% 几乎不变、市值保留近半。这类 token 可能代表了一种"低热度但有粘性"的社区模式，参与者不多但也不急于离场。

---

#### Cluster 6：高留存渐进型（20 个 token）

**核心特征**：中位 ATH $691K，6 小时到顶，MCap 保留率高达 **72.4%**。

**代表性 token**：BEAM, GAS, TRIPLET, PIZZA, ZORA, AUTISM

**生命周期画像**：
- **到顶速度**：中位 6 小时
- **Holder 增长**：+1%
- **ATH 后保留**：**72.4%**（第二高）
- **Holder 流失**：仅 -1%（几乎为零）
- **筹码变化**：-0.1pp（完全稳定）
- **ATH 后峰值回复**：93.3% of ATH（所有聚类中最高）

**解读**：C6 是非常值得关注的一类。它的 ATH 后市值保留率高达 72.4%，holder 几乎零流失，筹码分布保持稳定。6 小时的到顶时间说明这类 token 有一个相对健康的价格发现过程（不是一瞬间冲顶）。93.3% 的 ATH 后峰值回复率说明即使在 ATH 后的回调中，价格也经常回到接近 ATH 的水平。

**投资启示**：C6 代表了 Memecoin 中最接近"健康标的"的模式。如果一个 token 在 6 小时左右到顶、Top10% 在 17% 左右、holder 持续稳定不流失，它大概率属于 C6 类型，有 72% 的概率在 ATH 后仍保持较高的市值水平。

#### Cluster 7：高市值晚巅峰型（20 个 token）

**核心特征**：中位 ATH 最高（$1,153,704），到顶时间最晚（中位 12 小时），MCap 保留率最高（**75.0%**）。

**代表性 token**：CLANKER, GOYIM, PUNCH, Aliens, HODL, ELON

**生命周期画像**：
- **到顶速度**：中位 12 小时（所有聚类中最慢）
- **Holder 增长**：+2%
- **ATH 后保留**：**75.0%**（所有聚类中最高）
- **Holder 流失**：0%（ATH 后 holder 零流失）
- **筹码变化**：+1.3pp

**解读**：C7 是最"优质"的类型。最高的 ATH 市值说明市场给予了最高的估值，最晚的到顶时间（12 小时）说明有一个持续的、有机的上涨过程，75% 的市值保留率说明 ATH 后价值高度留存。特别值得注意的是 **holder 零流失**——在 ATH 之后没有人离场，这在 Memecoin 市场中极为罕见，暗示强烈的社区共识和持有信念。

**投资启示**：C7 是最值得关注和学习的模式。12 小时的渐进到顶过程 + 零 holder 流失 + 75% 市值保留，这三个指标组合代表了 Memecoin 中"最有机、最健康"的增长模式。如果一个新 token 在前 12 小时表现出缓慢但稳定的市值增长、同时 holder 持续进入不流失，它大概率属于 C7 类型。

## 三、跨聚类对比与关键发现

### 3.1 到顶速度与生存质量的关系

| 到顶时间 | 聚类 | MCap 保留率 | 解读 |
|---------|------|-----------|------|
| 0h（起步即顶） | C1, C4 | 1.7% / 43.6% | 两极分化 |
| 1-2h（快速到顶） | C2, C3, C5 | 27.8% / 20.8% / 43.9% | 中等留存 |
| 6h（渐进到顶） | C0, C6 | 2.6% / 72.4% | 两极分化 |
| 12h（慢热到顶） | C7 | 75.0% | 最高留存 |

数据显示，到顶速度本身并不能单独预测生存质量。C1 和 C4 同样是 0h 到顶，但保留率差异巨大（1.7% vs 43.6%）。C0 和 C6 同样是 6h 到顶，保留率差异更大（2.6% vs 72.4%）。**到顶速度必须结合 holder 动态和筹码分布才能做出有效判断。**

### 3.2 Holder 流失率是最强预测信号

| 聚类 | ATH 后 Holder 流失率 | MCap 保留率 |
|------|---------------------|-----------|
| C7 | **0%** | **75.0%** |
| C6 | **-1%** | **72.4%** |
| C5 | -5% | 43.9% |
| C2 | -4% | 27.8% |
| C4 | -11% | 43.6% |
| C3 | -10% | 20.8% |
| C0 | -18% | 2.6% |
| C1 | **-32%** | **1.7%** |

这是本次分析最重要的发现：**ATH 后的 holder 流失率与市值保留率存在近乎完美的负相关关系。**holder 零流失的 C7 保留了 75% 的市值，而流失 32% 的 C1 只保留了 1.7%。

这个信号的实用价值极高——在一个 token 到达 ATH 后，如果 holder 数量开始快速下降，这是一个强烈的退出信号；如果 holder 数量保持稳定甚至继续增长，这个 token 大概率能维持较高的价值水平。

### 3.3 Top10% 的双面性

Top10% 持仓集中度在不同聚类中扮演不同角色：

- **C2**（Top10% 25.7%，ATH 后下降 8.6pp）：高集中度 + 大幅下降 = 庄家出货。虽然短期保留率不差（27.8%），但大户减仓的趋势暗示中长期风险。
- **C7**（Top10% 21.6%，ATH 后上升 1.3pp）：中等集中度 + 轻微上升 = 大户加仓或散户离场后的被动集中。结合零 holder 流失来看，更可能是大户在加仓，这是看多信号。
- **C0**（Top10% 15.3%，下降 1.3pp）：低集中度 + 轻微下降 = 高度分散化社区。看似健康但实际保留率极低（2.6%），说明过度分散未必是好事——没有核心持仓者意味着没有"锚定力"。

### 3.4 核心结论：识别优质标的的三维模型

综合所有聚类的分析，我们提出识别优质 Memecoin 的三维模型：

**维度一：到顶时间（Time to ATH）**
- 最佳：6-12 小时（C6, C7 的范围）
- 风险：0 小时（起步即巅峰，但需要结合其他维度判断）

**维度二：Holder 流失率（ATH 后 1-3 小时内的 holder 变化）**
- 最佳：0% 或正增长（C7 的特征）
- 危险：> -10%（C0, C1 的特征，大概率不可逆下跌）

**维度三：Top10% 变化方向**
- 正面信号：Top10% 在 ATH 后轻微上升（大户加仓，如 C7）
- 负面信号：Top10% 在 ATH 后大幅下降（大户出货，如 C2）
- 中性信号：Top10% 保持不变（如 C5, C6）

## 四、四维状态空间查询系统

### 4.1 系统设计

基于上述聚类分析的成果，我们构建了一个实时查询系统。该系统在四维状态空间中为每个历史 token 的每个小时创建一个状态点，并使用 KD-Tree 索引实现快速近邻查询。

当输入一个新 token 的合约地址时，系统会：
1. 从 GMGN API 实时获取该 token 的当前数据
2. 在四维空间中定位其当前状态点
3. 找到历史上经过过相似状态点的 token
4. 展示那些历史 token 从该状态点之后的实际走势

### 4.2 距离度量优化

四维空间中不同维度的尺度差异巨大（mcap: $50K~$218M, holders: 1~152K, top10%: 0~100%, time: 0~200h）。直接使用线性尺度计算距离会导致 mcap 维度主导距离计算——$553K 和 $181K 在 0~$218M 的线性尺度上看起来完全相同。

我们通过对 mcap 和 holders 取对数来解决这个问题。对数变换后：
- log($50K) = 10.8, log($553K) = 13.2, log($218M) = 19.2
- 差异从线性尺度下的 0.17% 变为对数尺度下的 13%

这确保了同一数量级内的市值差异能被有效区分，同时跨数量级的差异也不会过度主导距离计算。

## 五、局限性与后续方向

### 5.1 当前局限

1. **样本量**：193 个 token 对于精细化的 8 类聚类来说仍然偏少，尤其是 C2 只有 5 个样本，统计显著性不足。
2. **时间窗口**：数据仅覆盖近期的 Solana Memecoin，市场风格随时可能变化（meta 轮换），历史模式对未来的预测力存在衰减风险。
3. **数据频率**：1 小时的数据间隔可能遗漏了分钟级别的关键事件（如瞬间闪崩或拉盘）。
4. **维度限制**：当前使用 4 个维度。未考虑交易量（volume）、买卖比（buy/sell ratio）、社交媒体热度等可能有价值的信号。

### 5.2 后续方向

1. **扩大样本量**：将历史 token 库扩展到 1,000+ 以提高聚类稳定性和预测可靠性。
2. **实时监控**：将查询系统集成为持续运行的监控服务，对新出现的 token 自动分类并发出预警。
3. **概率化预测**：不仅展示匹配 token 的走势，还输出概率分布——"基于历史相似 token，有 60% 概率在接下来 12 小时内下跌 >50%"。
4. **增加维度**：引入交易量、买卖比等维度，从四维升级到六维或更高维状态空间。
5. **时间衰减**：对历史匹配引入时间衰减权重——近期的 token 行为模式对当前市场的参考价值高于早期 token。

## 六、总结

本研究通过构建四维状态空间（时间 × 市值 × 持币地址数 × Top10 持仓集中度），对 193 个 Solana Memecoin 进行了系统性的轨迹聚类分析，发现了 8 种不同的行为模式。

**最值得关注的两个聚类是 C6（高留存渐进型）和 C7（高市值晚巅峰型）**，它们共同的特征是：6-12 小时的渐进到顶过程、ATH 后 holder 接近零流失、Top10% 保持稳定或轻微上升。这两个指标的组合可以作为识别"优质 Memecoin"的核心信号。

四维状态空间查询系统为实时决策提供了一个基于历史轨迹匹配的参考框架。虽然它不能预测未来，但它可以回答一个关键问题：**"历史上，和当前状态相似的 token，后来发生了什么？"**——这本身就是极有价值的决策信息。
